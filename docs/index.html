Tính năng Features

Những gì có sẵn trong app. What ships in the box.

Không cần cài thêm extension. Tất cả các tính năng dưới đây đã có sẵn và hoạt động độc lập. No extensions required. Everything below is built in and works out of the box.

Adblock engine
Dùng crate adblock-rust của Brave trên một OS thread riêng. Bundle EasyList, EasyPrivacy và Fanboy's Annoyance. Thêm rule cá nhân được. Uses Brave's adblock-rust crate on a dedicated OS thread. Bundles EasyList, EasyPrivacy, and Fanboy's Annoyance. Custom rules supported.
adblock-rust
Password vault
Master password hash bằng Argon2id. Từng credential mã hoá AES-256-GCM với nonce riêng. Auto-lock sau 10 phút idle, rate-limit chống brute-force. Master password hashed with Argon2id. Each credential encrypted with AES-256-GCM and a unique nonce. Auto-locks after 10 minutes idle, rate-limited against brute force.
Argon2id · AES-256-GCM
Tải đa luồng Multi-threaded downloads
Chia file thành 4 đến 16 phần và tải song song qua HTTP Range khi server hỗ trợ Accept-Ranges. Tự bắt link tải từ WebKit. Splits files into 4 to 16 segments fetched in parallel via HTTP Range when the server advertises Accept-Ranges. Intercepts download events from WebKit.
4–16 TCP · Range
Tab snoozer
Tab không hoạt động quá 10 phút sẽ được ẩn webview để giải phóng tài nguyên. State được giữ nguyên, chọn lại tab không cần tải lại trang. Tabs idle for over 10 minutes have their webview hidden to reclaim resources. State is preserved, so re-selecting a tab does not reload the page.
10 min idle
WebRTC leak shield
Loại bỏ IP nội bộ (RFC 1918, link-local IPv6) khỏi SDP candidate trong RTCPeerConnection. Kèm farbling Canvas và AudioBuffer. Strips internal IPs (RFC 1918, link-local IPv6) from SDP candidates in RTCPeerConnection. Includes Canvas and AudioBuffer farbling.
SDP · Farbling
Clean URL & De-AMP
Bỏ tham số tracking (utm_*, fbclid, gclid, si, spm...) trước khi navigate. Chuyển URL Google AMP về canonical. Strips tracking parameters (utm_*, fbclid, gclid, si, spm) before navigation. Rewrites Google AMP URLs to canonical.
27 keys · AMP
Kiến trúc Architecture

Hai lớp, giao tiếp qua Tauri IPC. Two layers, communicating over Tauri IPC.

UI và backend là hai process độc lập. Trang web render trong webview native của WebKitGTK, không dùng <iframe>. UI and backend run as separate processes. Web pages render in native WebKitGTK webviews, not <iframe> elements.

UI layer — Leptos CSR + Rust WASM UI layer — Leptos CSR + Rust WASM

Chạy trong webview main. Render tab strip, omnibox, download shelf và các view nội bộ. Giao tiếp với backend qua Tauri IPC bất đồng bộ. Runs inside the main webview. Renders the tab strip, omnibox, download shelf, and internal views. Talks to the backend over async Tauri IPC.

Vibird là trình duyệt phụ, không được thiết kế để thay thế trình duyệt chính. Nếu bạn cần extension phong phú, đồng bộ đa máy, DRM, hoặc tương thích web tối đa, hãy dùng Brave hoặc Firefox. Vibird phù hợp khi bạn muốn một trình duyệt nhẹ, không telemetry, có sẵn adblock và tải file nhanh. Vibird is a secondary browser, not a drop-in replacement for your primary one. If you need rich extensions, cross-device sync, DRM, or maximum web compatibility, use Brave or Firefox. Vibird fits when you want a lightweight, telemetry-free browser with built-in adblock and fast downloads.
