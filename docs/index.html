Tính năng Features

Những gì có sẵn trong app. What ships in the box.

Không cần cài thêm extension. Tất cả các tính năng dưới đây đã có sẵn và hoạt động độc lập. No extensions required. Everything below is built in and works out of the box.

Adblock engine
Dùng crate adblock-rust của Brave trên OS thread riêng. Parse EasyList (~300k rules) thành ~8000 domain blocks + 500 substring. Per-site exceptions. Uses Brave's adblock-rust on a dedicated OS thread. Parses EasyList (~300k rules) into ~8000 domain blocks + 500 substring. Per-site exceptions.
adblock-rust · EasyList
Password vault
Argon2id hash master password. AES-256-GCM per record, nonce riêng. Auto-lock 10 phút idle, rate limit chống brute-force, zeroize key khi drop. Argon2id master password. AES-256-GCM per record, unique nonce. Auto-lock after 10 min idle, rate-limited against brute force, zeroize key on drop.
Argon2id · AES-256-GCM
Tải đa luồng Multi-threaded downloads
Chia file thành 4–16 phần, tải song song qua HTTP Range khi server hỗ trợ Accept-Ranges. Tự bắt link tải từ WebKit. Splits files into 4–16 segments fetched in parallel via HTTP Range when server advertises Accept-Ranges. Intercepts download events from WebKit.
4–16 TCP · Range
Tab snoozer
Tab idle quá 10 phút tự động ẩn webview để giải phóng tài nguyên. State giữ nguyên, chọn lại không cần tải lại trang. Tabs idle over 10 minutes have their webview hidden to reclaim resources. State preserved, re-selecting doesn't reload the page.
10 min idle
Privacy shields

WebRTC · Farbling
